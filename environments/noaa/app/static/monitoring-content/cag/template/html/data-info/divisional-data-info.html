Offline data information

Offline NClimDiv release 20260904. January 1895–August 2026, 344 climate divisions and 48 states. Temperature, precipitation, heating and cooling degree days, and Palmer indices. County, city, global and regional products are not implemented here.

Parameters and calculations

Temperature (°F) and Palmer Z-Index use the average of the selected months. Precipitation (inches), heating and cooling degree days (°Df, base 65°F) use the sum. PDSI, PHDI and PMDI support one month only. Anomaly is departure from the 1901–2000 mean of the same calendar window. Palmer indices are dimensionless; positive values indicate wetter conditions.

A window with a missing month has no value. Months after August 2026 and windows extending before January 1895 have no data. Invalid parameters are reported separately from unsupported products. Map, table and downloads use the same query.

Rank uses the lowest position among tied displayed values, and JSON includes the complete rank–rankEnd interval. Use Location, Parameter, Year, Month and Time Scale, then Plot. Value, Anomaly, Rank and Mean change the map display. The source CAG table preserves its side-by-side value columns. Click a map division to open its time series. CSV, JSON and XML downloads are local.
