Understanding ACS data

Products and years

ACS 5-year estimates pool 60 months of observations. A display year of 2018 refers to 2014–2018. ACS 1-year estimates describe a single year and are published for eligible geographies with populations of 65,000 or more. Availability must be verified from that year's release, not inferred from this threshold alone.

Estimates, uncertainty and missing data

The estimate and 90% margin of error (MOE) are separate published statistics. A dash, (X), N, ** or *** is not zero. Ordinary negative values are valid numbers; only documented Census special codes or source annotations denote unavailable estimates. Annotations remain attached to their cells. A median shown as 2,500- is a bounded estimate, not exactly 2,499 or 2,500. Read source annotations when interpreting bounded or annotated medians. Numeric filters exclude annotated estimates. Margins of error follow the individual source tables. Dollar values use the inflation adjustment year named in each table.

Statistical universe

Each table describes its own universe. Households, housing units, renter-occupied units and civilian noninstitutionalized populations are not interchangeable. Open a variable's label for its full hierarchy and identifier.

Downloads and precision

CSV and Excel export the complete customized view, including rows beyond the current scroll position. ZIP exports all archived data for the selected geographies and ignores table customizations. Historical CSV sources preserve published formatted values.

Access modes

The browser can inspect and download displayed data. Local table and metadata endpoints support these browser operations. A bounded Census API mode supports get, for and in over archived data at /data/{year}/acs/{acs5|acs1}. Unarchived requests fail explicitly; numerical results retain source precision and annotations. Browser and API runs are distinct evaluation modes.
