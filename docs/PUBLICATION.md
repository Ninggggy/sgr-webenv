# Materials

The repository contains website applications, deployment configurations and preparation tools. Data and image locations are recorded in the [release manifest](../releases/v0.1.3.json).

Use `python3 tools/env.py prepare <site> --release v0.1.3` to obtain the corresponding resources. NOAA uses [local image builds](../environments/noaa/README.md).

See [operation](OPERATIONS.md) and [component terms](THIRD_PARTY.md).
